# Nexus 작문퀴즈 스테이지 관리

## 요약

Nexus 단어 퀴즈의 작문 단계는 `stage >= 3`부터 적용된다.
자동 복습 모드에서 작문 정답으로 처리되면 단어 단계가 올라가고, 다음 리뷰일이 단계별 간격에 맞춰 갱신된다.

수동 연습 모드(`/quiz`)에서는 작문 정답이어도 단어 단계가 갱신되지 않는다.

## 단계별 다음 리뷰일

| 현재 단계 | 정답 후 다음 단계 | 다음 리뷰일 |
| --- | --- | --- |
| 1단계 | 2단계 | 3일 뒤 |
| 2단계 | 3단계 | 7일 뒤 |
| 3단계 | 4단계 | 30일 뒤 |
| 4단계 | 5단계 | 60~120일 뒤 랜덤 |
| 5단계 | 6단계 | 9999일 뒤 |

## 4단계 이후 처리

4단계에서 정답이면 5단계가 된다.
5단계는 고정 리뷰 간격 상수에는 없지만, 스테이지 업데이트 로직에서 별도로 처리된다.

5단계로 올라갈 때는 다음 리뷰일이 60일에서 120일 사이의 랜덤 값으로 잡힌다.
5단계에서 다시 정답이면 6단계로 이동하며, 6단계는 졸업 단계다.

```text
3단계 작문 정답
  ↓ 30일 뒤
4단계 작문 정답
  ↓ 60~120일 뒤 랜덤
5단계 작문 정답
  ↓ 9999일 뒤
6단계 졸업
```

## 졸업 단어 출제 여부

자동 복습 대상 조회는 `단계 < 6` 조건을 사용한다.
따라서 6단계 졸업 단어는 자동 복습에 다시 나오지 않는다.

추가로 6단계가 될 때 다음 리뷰일도 9999일 뒤로 설정된다.

## 작문에서 살짝 틀린 경우

작문 정답 여부는 단순히 문법 오류가 있는지로만 결정되지 않는다.
핵심은 목표 단어를 사용했는지와 의미 전달이 맞는지다.

| 상황 | 스테이지 처리 | 다음 동작 |
| --- | --- | --- |
| 목표 단어 사용, 의미 전달 성공, 문법/연어 오류 있음 | 정답 처리, 단계 상승 | 교정 문장 재시도 요청 |
| 의미는 맞지만 목표 단어를 안 씀 | 단계 변화 없음 | 같은 문제 재시도 |
| 목표 단어는 썼지만 의미 전달 실패 | 단계 변화 없음 | 최대 5회까지 재시도 |
| 목표 단어도 안 쓰고 의미도 틀림 | 1단계로 리셋 | 다음 문제로 이동 |

## 관련 코드 위치

| 역할 | 위치 |
| --- | --- |
| 작문 채점 분기 | `nexus/services/quiz_flow.py::_grade_writing_answer` |
| 일반 답안과 작문 답안 분기 | `nexus/services/quiz_flow.py::grade_answer` |
| 단어 단계 및 다음 리뷰일 갱신 | `nexus/services/notion_service.py::update_word_stage` |
| 단계 간격 상수 | `nexus/constants.py` |
| 자동 복습 대상 조회 | `nexus/services/notion_service.py::get_words_due` |
