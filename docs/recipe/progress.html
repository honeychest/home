  • 1~3차 동안은 사용자 준비물 없음. Gemini API 키·재생목록 일부공개는 4차 진입 전에 준비하면 됨

작업 체크리스트

프론트 단독 (localStorage · 모바일 전용)
  • 1차: 디자인 기반 + 앱 골격 + 냉장고 화면
    • grill-me 점검 (4탭 골격·홈 컨셉·토글 추가·앱 이름 기까)
    • 디자인 인터뷰 — "냉장고 문 × 프레시" 확정 (그린+자석 스티커, 다크 자동전환)
    • tokens.css (색·간격·글자 테마 세트, 라이트/다크)
    • recipe UI 킷 + /recipe/styleguide 페이지
    • 앱 골격: 하단 탭 4개 (홈/추천/냉장고/레시피) + PWA manifest (이름 '기까')
    • 저장소 인터페이스 + localStorage 구현체
    • 냉장고 화면: 선반 3칸(임박/오래됨 14일/신선, 스냅 가로 스크롤) / 스티커 탭→시트 / 토글 추가(시드 12개)
    • 폰에서 실사용 검수 → 피드백 반영 → 홈화면 추가 (크롬 기준)
  • 2차: 레시피 목록·상세 + 추천 화면 (샘플 레시피로)
  • 3차: 등록 화면 (URL 입력·진행률 — 동작은 흉내만)
사용자 검수: 반복 수정 → "완전해지면" 아래 진행
  • 4차: PostgreSQL recipe DB + API, 냉장고부터 저장소 교체
  • 5차: Gemini 추출 + 재생목록 일괄 등록 연결 (품질 검증 지점)
    • 사용자: Gemini API 키 발급 (결제 연결 금지 — 무료등급 소멸)

  • 6차: 다듬기 (자주 사는 재료 버튼, 새 재료 분류 질문, 진행률 실동작)
